# 공식 규격 원문

이 폴더에는 동일한 Release와 버전으로 고정한 ETSI 발행 3GPP 규격 PDF 두 개가 있다.

| 파일 | 역할 | 사용 범위 |
|---|---|---|
| `ts_123501v181200p.pdf` | 주 원문 | 3GPP TS 23.501 V18.12.0, 조항 4-8 |
| `ts_124501v181200p.pdf` | 적격 보조 원문 | 3GPP TS 24.501 V18.12.0, 조항 4-6 |

주 원문은 5GS 아키텍처 요구를 다루며 현재 연구 질문과 가장 직접적으로 맞는다. 보조 원문은 NAS 절차 요구를 다루며, 주 원문에서 희소한 `should not` 후보를 보완할 수 있다.

두 문서를 곧바로 섞어 표본을 만들지는 않는다. 먼저 `should not` 후보를 사람이 검토한 뒤 다음 중 하나를 결정한다.

1. TS 23.501만으로 pilot 3개와 main 12개를 모두 충족하면 단일 문서 설계를 유지한다.
2. 부족하면 두 규격에서 각 modal 범주를 균형 있게 뽑아 `spec_id`와 `modal_class`의 교란을 막는다.

정확한 URL, 해시, 페이지 수, 사용 범위는 `../source_manifest.json`과 `../source_inventory.md`에서 확인한다. 저장소 공개나 외부 배포 전에는 ETSI/3GPP 원문의 재배포 조건을 별도로 확인한다.
