# 추가 검토 자료 — 아직 판정하지 않은 15개 응답

이 자료는 미확정이 남은 세 원문에서 모든 비교 조건의 응답을 하나씩 포함한다. 15건 전체의 새 판정을 아직 받지 않았으며, 독립 전문가 검토를 완료한 자료가 아니다. 현재 평가자가 기존 판정을 알고 있으므로 파일에서 조건명·이전 판정을 숨긴 사실을 완전한 눈가림으로 주장하지 않는다. 원문 제공 여부나 응답 내용에서 조건을 추론할 수도 있다.

1. 저장된 빈 양식을 별도 작업 경로에 복사한다. 봉인된 양식과 원본을 덮어쓰지 않는다. `packets_15.jsonl`과 `judgments_blank_15.jsonl`은 `review_id`로 연결한다.
2. [동결 규칙](../../../../experiments/scoring_v2_frozen_20260908.md)을 읽고, 원문·질문·한국어 설명 전체를 대조한다. 기존 판정·조건 키는 판정 작성 전 열지 않는다. gold 유형이나 추출 힌트로 한국어 설명의 모호한 부분을 대신 채우지 않는다.
3. [문맥 자료](../context_candidates.jsonl)의 같은 `reference_id` 페이지들을 확인한다. 추가 PDF 문맥은 **판정자 전용**이며 원래 모델에 추가 문맥으로 제공되지 않았다. `reference_source_available_to_original_generator`는 원래 짧은 원문 제공 여부다. PDF 페이지 번호는 1부터 센다. TXT에는 추출 과정의 줄바꿈·공백이 있으므로 같은 경로의 PNG 또는 원본 PDF로 확인한다.
4. 관련 없는 주변 문장, 다른 절, NOTE까지 전부 필수 명제로 삼지 않는다. 페이지 묶음은 경계 확인 자료이지 동결된 새 prompt가 아니다. Annex C 전체 및 모든 상호 참조를 다 확인한 것으로 해석하지 않는다.
5. 원문 인용, 응답의 정확한 인용, 적용 규칙, 명제 연결의 근거를 남긴다. `PASS=1`, `FAIL=0`, `UNRESOLVED=null`이다. 동결 기준만으로 정할 수 없으면 `frozen_rule_sufficient=false`와 이유를 적는다. 새 규칙이 필요하면 `new_rule_proposal_if_needed`에 제안만 남기고 기존 점수에는 적용하지 않는다. 설명 미생성은 동결 기준의 별도 pipeline 처리를 따른다.
6. 평가자의 이름 또는 식별자, 전문성/역할, 실제 검토 시간을 기록한다. 이 세 원문의 15개 조건 응답 전체에 같은 기준을 적용한다. 이후 작성 결과를 별도로 봉인한 뒤 기존 판정과 대조한다. 이 범위 밖 사례에 영향을 주는 해석이면 범위를 넓혀 대칭 검토한 다음 반영한다.

검토자에게는 이 안내·두 JSONL·원문 문맥 자료·동결 규칙을 제공한다. 상위 폴더의 후속 결론과 `coordinator/keys_15.jsonl`은 기존 판정을 대조할 때 사용한다. 현재 외부 검토자에게 전송하지 않았으며 일정이나 독립성은 확보되지 않았다.
