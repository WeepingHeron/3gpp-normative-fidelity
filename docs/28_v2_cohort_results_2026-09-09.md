# v2 조정 반영 조건별 결과와 네 동결 집합의 민감도

2026-09-09. **주 분석 49건에서 C2−C1의 보존율 차이는 +10.20~+16.33%p이고, 세 민감도 집합에서도 방향이 유지된다. C2와 C1M의 우열은 미확정 처리에 따라 달라질 수 있다.** 이는 고정된 사례·응답과 현재 판정에 한정된 기술적 비교다. 모든 범위는 미확정 상태에 대한 논리적 외곽 범위이며 통계적 신뢰구간이 아니다.

상태는 `COHORT_BOUNDS_COMPLETE_INFERENCE_DEFERRED`다. [불일치 조정 결과](27_v2_disagreement_adjudication_2026-09-09.md)를 [동결된 처리 계약](../experiments/posthoc_treatment_v1_20260908/protocol.json)의 네 집합과 연결했다. 255개 원본 응답 레코드를 일대일로 대응시켰고, 판정이나 집합을 변경하지 않았다. 독립 전문가 검증, 새 모델 실험, 전체 3GPP에 대한 일반화로 읽지 않는다.

## 조건과 집합

| 조건 | 입력·처리의 의미 |
|---|---|
| C0 | 질문만 제공하는 closed-book 기준선 |
| C1 | 원문과 질문을 제공하는 설명 조건 |
| C2 | 원문·질문과 사람이 구성한 gold 구조를 제공하는 oracle structured 조건 |
| C3 | 원문 기반 자동 구조 추출 후 사용 가능한 추출 결과로 설명을 생성하는 조건 |
| C1M | 원문·질문에 규범 유형과 극성의 gold 힌트를 제공하는 조건 |

## 집계 정의

N은 조건마다 동일하게 고정한다. P는 PASS, F는 FAIL, U는 UNRESOLVED, NG는 설명 미생성 등 NOT_SCORED이며 **P+F+U+NG=N**이다. 포함된 NG는 pipeline 결과 0으로 유지하지만 의미 오역 F와 별도로 보고한다. U는 원자료에서 null로 유지하고 분석에서 제거하지 않는다.

- 조건별 범위: **[P/N, (P+U)/N]**.
- B−A 차이 범위: **[(P_B−P_A−U_A)/N, (P_B+U_B−P_A)/N]**.

표시 비율은 소수 둘째 자리로 반올림했고, 계산에는 정수 분자와 N을 사용했다. 차이 단위는 %p다. 미확정 응답별 가능한 0/1 판정을 넓게 허용한 범위로, 같은 원문에서 생긴 미확정 간 제약을 추가로 가정하지 않는다. 미확정이 서로 독립인 확률변수라는 가정이나 모집단 불확실성 추정은 아니다.

## 사전에 이 처리 버전에 지정한 비교

C2−C1의 PRIMARY_STRICT_49가 이 사후 버전의 주 비교이며, 나머지는 민감도 또는 탐색 비교다. 아래 16개 비교 모두 U가 있어 exact McNemar, case bootstrap, clause cluster bootstrap의 확정 추론값을 산출하지 않았다. 비교 대상 조건의 Wilson 구간도 U를 임의로 확정해 계산하지 않았다. C0는 기술적 기준선으로만 제시한다.

| 집합 | C2−C1 | C3−C1 | C1M−C1 | C2−C1M |
|---|---:|---:|---:|---:|
| PRIMARY_STRICT_49 | +10.20~+16.33%p | +4.08~+10.20%p | +8.16~+14.29%p | -2.04~+6.12%p |
| SENS_GOLD_50 | +8.00~+14.00%p | +2.00~+8.00%p | +6.00~+14.00%p | -4.00~+6.00%p |
| SENS_EXCEPTION_50 | +10.00~+16.00%p | +4.00~+10.00%p | +8.00~+14.00%p | -2.00~+6.00%p |
| SENS_GOLD_EXCEPTION_51 | +7.84~+13.73%p | +1.96~+7.84%p | +5.88~+13.73%p | -3.92~+5.88%p |

C2−C1, C3−C1, C1M−C1은 네 집합 모두 하한이 0보다 크다. 따라서 현재 확정 판정을 유지하는 한 미확정의 가능한 처리만으로 이 집합 내부의 차이 방향이 뒤집히지는 않는다. **통계적 유의성이나 모집단 우월성의 증거는 아니다.** C2−C1M은 네 집합 모두 0을 포함하므로 C2가 더 높다고 확정할 수 없다.

주 비교를 정수로 확인하면 C1은 PASS 38·U 1, C2는 PASS 44·U 2이며, 차이 분자는 44−38−1=5부터 44+2−38=8이다. 이를 고정 N=49로 나눈 결과가 +10.20~+16.33%p다.

## 두 포함 결정이 바꾸는 부분

| 추가 사례 | C0 | C1 | C2 | C3 | C1M |
|---|---|---|---|---|---|
| MAIN-MAY-001 | FAIL | PASS | FAIL | FAIL | UNRESOLVED |
| MAIN-SDN-011 | FAIL | FAIL | FAIL | FAIL | FAIL |

MAY-001을 더하면 C1의 확인된 PASS가 하나 늘고 C1M의 U가 하나 늘어난다. SDN-011은 이 기준에서 모든 조건이 FAIL이라 PASS 분자를 늘리지 않고 분모를 늘린다. 이 결과를 보고 집합을 선택한 것이 아니라, 이미 동결한 두 포함 결정의 영향을 기록한 것이다. MAY-001에서 C2가 FAIL인 사실과 잘못된 gold 입력은 연결된 연구상 제한이지만 단일 사례로 실패의 인과 원인을 입증하지 않는다.

## 남은 불확실성과 해석 한계

합집합의 U 8건은 G023 4건(C1·C2·C3·C1M), G028 3건(C2·C3·C1M), G010 1건(C1M)이다. G010/MAY-001은 지정 gold 민감도 두 집합에만 포함되므로 주 분석의 U 합계는 7건이다. G023·G028의 범위 문제는 동일 평가자의 반복 검토나 조정만으로 해소되지 않았다.

서로 같은 조항의 사례들은 의존할 수 있다. 군집 수는 현재 집합에서 spec_id+clause_id로 다시 계산했으며 과거 전체 72건의 값을 재사용하지 않았다. U 때문에 bootstrap은 수행하지 않았고, 군집 수 자체도 군집 독립성을 보장하지 않는다.

기존 v1/v4와 이번 v2는 채점 기준과 대상 집합이 다르다. 기존 수치와의 차이를 모델 향상이나 새로운 생성 효과로 해석하지 않는다. 본 분석은 같은 기존 응답의 사후 재평가다. 원본 source·question·gold·응답과 v4 원고를 보존했으며 논문 수치는 이번 작업에서 갱신하지 않았다.

## 검증 평가: Share with caveats

**방법론:** 네 동결 집합의 정확한 case ID와 동일 조건 분모를 확인했다. 51개 사례·5조건의 255개 응답을 원본 레코드 해시로 연결했고, 미확정 제외나 조건별 표본 변경을 하지 않았다. 20개 조건 결과와 16개 비교를 빠짐없이 기록한다.

**계산 교차검증:** 별도의 SQLite 경로에서 원본 조정 판정과 case 매핑을 결합해 20개 결과의 네 상태 건수를 다시 계산했다. 각 비교의 모든 미확정 0/1 조합을 열거해 차이의 최솟값·최댓값을 검증했다. 이는 미확정의 실제 판정을 바꾸는 작업이 아니다. 800개 paired-case 기록은 네 겹치는 집합과 네 비교에 반복 등장한 대응 내역으로, 800개의 독립 사례를 뜻하지 않는다.

**주요 제한:** 미확정과 동일 평가자의 사후 판정 때문에 확정 통계 추론 및 일반화 주장은 보류한다. 표의 논리적 범위를 신뢰구간으로 읽지 않아야 한다. 그래프 없이 정확한 건수·분모를 확인할 수 있는 Markdown 표와 기계 판독 자료로 제공한다.
