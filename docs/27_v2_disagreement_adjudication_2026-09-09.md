## 판단 근거와 대칭 적용

[동결된 v2 기준](../experiments/scoring_v2_frozen_20260908.md)의 R1·R3·R4·R8을 적용했다. rubric을 편집하거나 새로운 규칙을 동결한 것은 아니다. 다만 아래 내용은 관찰된 불일치를 조정하기 위한 **사후 해석의 명시**이며, 처음부터 사전 등록된 세부 판단이라고 주장하지 않는다.

**설명 전체에서 실제 관계가 바뀌었는지 확인했다.** 019의 첫 문장은 Active Time 할당 때 all-PLMN 등록 영역을 피하라는 권고를 완결한다. 뒤 문장은 paging 회피 목적을 다시 설명하며, 다른 상황에서 권고가 사라진다는 말이나 그 경우에만 적용된다는 배타적 한정은 없다. 따라서 ‘조건’이라는 단어만으로 첫 문장의 범위가 변경됐다고 단정했던 2차 해석을 채택하지 않았다. 반대로 G031의 128은 권고를 가능한 한 작은 영역의 설정 의무로 바꿔 FAIL을 유지한다.

**규범 명칭만으로 중첩된 능력의 범위를 대체하지 않았다.** 070은 능력 보유가 선택적이라는 표현을 명시한다. 기술적 가능성이라는 말은 그 안의 능력을 설명할 수 있으며, 모든 SMF가 이미 능력을 가진다고 확정하지 않는다. 그러나 062는 능력 보유를 생략하고 제어 행위의 허가로 바꾸며, 158은 각 SMF의 제어 가능성을 확정한다. 두 설명은 FAIL을 유지한다. 106은 보유 확정과 선택 가능 부연의 연결이 불분명하여 R3의 UNRESOLVED를 적용한다. ‘선택 가능’이라는 단어가 있다는 이유만으로 PASS하지 않았다.

G006·G008·G004에서 can을 명시적인 행위 허가로 바꾼 설명도 함께 확인했다. 이들은 070처럼 선택적인 능력 보유를 중첩해 남기지 않으므로 기존 FAIL을 유지한다. G037의 ‘기술적 가능성이 있어야 한다’는 의무와 내부 능력을 함께 남겨 PASS를 유지한다.

**명시된 대상 오류와 생략된 대상의 복원을 구분했다.** 099·151은 엔티티가 NAS에 의해 무결성 검사를 받은 것으로 서술한다. 독자가 검사 대상을 메시지로 고쳐 읽어야 하므로 단순한 어순·문체 차이로 처리하지 않았다. 151의 마지막 문장도 검사 성공만 언급하고 대상 오류를 바로잡지 않는다. 반면 같은 기준의 048·156은 엔티티를 처리 주체의 화제로 두며 검사 대상이 생략돼 뒤의 NAS 메시지로 복원될 수 있다. 두 설명은 PASS를 유지한다. 조사 하나로 판정을 자동 결정하는 규칙을 만든 것은 아니며, 각 문장의 주절·조건절과 전체 지시 관계를 대조한 판단이다.

R3의 보완 사례인 G005/137도 함께 확인했다. 이 응답은 뒤 문장이 실제 context establish를 전제조건이라고 명시하므로 PASS다. 필요한 행위를 구체적으로 복원하는 경우와 잘못된 검사 대상을 그대로 남기는 151을 구분했다.

## 확인 범위

불일치가 발생한 G010·G031·G050의 **모든 5조건, 15개 응답**을 확인했다. 이어 목적 재언급, can과 허가 구분, 중첩된 능력, 뒤 문장의 보완이라는 연결 쟁점에 해당하는 G001·G003·G004·G005·G006·G008·G009·G025·G037의 모든 조건 45개 응답을 확인했다. 합계 **12개 기준 × 5조건 = 60개 응답**이다.

이 범위는 불일치 내용을 본 뒤 쟁점에 따라 선정했다. 60개 모두 원문과 전체 응답을 읽고 개별 판정 이유를 작성했다. 불일치 5건 외에 두 차수가 일치했던 55건에서는 추가 상태 변경이 없었다. 다른 195건은 두 차수의 일치 결과를 조정 반영 자료에 연결했으며, 이번에 전체 255건을 세 번째로 다시 검토했다고 주장하지 않는다. 두 차수의 일치 자체도 의미적 정답을 보증하지 않는다.

이 수치는 검토 상태 건수이며 조건별 정확도나 논문 최종 성능이 아니다. 250건은 두 차수의 일치 결과를 연결하고, 5건은 명시적 조정 결과를 적용했다. 조정 후 일치율을 다시 높여 보고하지 않으며, 조정 전 두 차수의 상태 일치는 여전히 250/255다.

남은 미확정 8건은 다음과 같다.

- **G023의 4건:** Annex C의 실제 저장 예외를 어느 입력 범위까지 채점할지 미해결이다.
- **G028의 3건:** NR 위성 접속이라는 상위 문맥이 원래 입력에 없었던 범위 문제다.
- **G010의 1건:** 위의 106으로, 응답 자체의 지시 대상 모호성이다.

G023·G028의 기존 미확정은 이번 불일치 조정으로 해소됐다고 간주하지 않는다. 해당 두 기준에 연결된 다른 3건은 문맥 문제와 독립적인 명백한 오류에 근거한 FAIL을 유지한다. 설명 미생성 1건도 의미 오역과 구분해 NOT_SCORED 및 pipeline 값 0을 유지한다.

모든 미확정은 해당 동결 집합의 분모에 남긴다. 다음 조건별 보고에서는 집합별 PASS/N과 (PASS+U)/N 및 U를 함께 제시하고, 미확정이 영향을 미치는 비교의 확정 통계 검정을 보류해야 한다. 주 분석과 민감도 분모 49/50/50/51, 원본 생성 입력과 응답, 기존 점수·원고는 유지했다. 이번 작업에서 조건별 성능 계산이나 논문 수치 갱신, 새로운 모델 생성 API 호출은 하지 않았다.
