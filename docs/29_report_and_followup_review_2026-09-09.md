## 추가로 확인한 근거와 판정

두 원본 PDF의 관련 10쪽을 텍스트와 페이지 이미지로 확인했다. 이미 확인했던 쟁점을 더 넓은 페이지 문맥과 실제 보관 요청에 연결한 후속 검토다. 별개의 정답 발견이나 독립 평가자의 반복 실험이 아니다.

| 대상 | 유지한 미확정 | 확인한 범위 | 이번 결론 |
|---|---|---|---|
| G023 / MAIN-SD-005 | C1·C2·C3·C1M 4건 | TS 24.501 §4.6.2.2, Annex C.1/C.2. PDF 98, 1089–1093쪽 | 부속서에는 모드별 저장 조건과 예외가 있다. 원래 제공되지 않은 부속서 본문을 사후 필수 명제로 추가하지 않고, 참조를 유지한 설명의 채점 범위 불확실성을 남긴다. |
| G028 / MAIN-SDN-003 | C2·C3·C1M 3건 | TS 23.501 §5.4.11, §5.4.11.4와 경계. PDF 132–134쪽 | NR 위성 접속 상위 범위와 망 설정을 재확인했다. 입력 문맥 부족과 설명 자체의 오역을 분리하며 미확정을 유지한다. |
| G010 / MAIN-MAY-001 | C1M 1건 | TS 23.501 §4.2.3. PDF 45쪽 | 원문의 선택적 능력 보유는 명확하다. 응답의 “능력이 있다. 이는 허용 또는 선택 가능”에서 지시어가 보유 여부를 명확히 정정하는지는 추가 원문으로 결정할 수 없다. |

G023의 Annex C.1은 SNPN access operation mode가 아닌 UE를 다룬다. 해당 절의 긴급 등록·eCall only 문단에는 USIM/비휘발성 저장 금지와 ME 임시 저장·삭제가 있다. C.2는 SNPN 모드의 등록 상태와 자격증명 관련 분기를 둔다. C.1에서 확인한 세부 조건을 모든 SNPN 상황에 무조건 확장하지 않는다. 선택한 쪽만 확인했으며 Annex C 전체와 모든 참조 규격을 완전 검토했다고 주장하지 않는다.

G028은 §5.4.11.1의 NR 위성 접속 범위와 §5.4.11.4의 망 설정·위치 검증 문맥 안에 있다. G010은 여러 PDU Session과 두 SMF를 설명하는 직전 문단 다음에 오는 본문이다. 이 문맥 확인은 각각 기존 범위 문제와 R1 해석을 뒷받침하지만, 그 자체로 현재 미확정을 0/1로 바꾸는 근거는 아니다.

## 실제 생성 입력과의 경계

C3의 세 사례별 추출·생성 요청 6건과 C1M 생성 요청 3건, 총 9건을 보관 `requests.jsonl`의 실제 입력 문자열과 요청 SHA-256에 대조했다. Annex C 모드·긴급/eCall 본문과 NR satellite access 상위 문맥은 이 입력들에 추가 문맥으로 들어 있지 않다. C1M의 MAY-001은 permission 힌트를 받았지만, 힌트의 올바른 유형 이름이 한국어 응답 지시어의 의미를 대신 확정하지 않는다.

[요청별 대조 기록](../outputs/review/v2_followup_20260909/archived_request_checks.jsonl)은 원래 파일·행·요청 해시와 전체 입력을 보존한다. C1/C2의 같은 형태의 요청 로그까지 직접 확인한 것으로 확대하지 않는다. 해당 조건은 이전 봉인 자료의 입력 가용성 바인딩을 사용한다. 단순 키워드 부재만으로 판정한 것이 아니라 전체 입력을 읽었으며, 키워드 필드는 보조 확인 기록이다.

## 결과를 다시 반영할 기준

기존 결과를 고칠 만한 수준은 미확정 수가 단순히 줄어드는 것이 아니다. 새 문서 근거 또는 독립 검토자가 남긴 명시적 판정 근거가 동결 규칙으로 기존 불확실성을 해소하고, 관련 모든 조건에 대칭 적용되며, 응답·출처·판정 연결과 집계 검증을 통과해야 한다. 그때 별도 조정 버전을 만들고 조건별 범위와 해석이 어떻게 달라졌는지 보고한다. 일부 미확정이 남아도 실제 변경과 잔여 불확실성을 함께 보고할 수 있다.

새 기준·문맥·모델 응답이 필요하면 후속 실험으로 보고한다. 같은 평가자의 재독만으로 얻은 확신이나 반복 일치율은 독립 타당도 근거로 승격하지 않는다. 이번 검토에서는 점수 변경 0건, 새 모델 생성 0건이며 독립 검토자 검토와 새 실험은 아직 수행하지 않았다. 외부 전송이나 예약 실행도 하지 않았다.
