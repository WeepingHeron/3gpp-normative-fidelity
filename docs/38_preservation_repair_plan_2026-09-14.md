# 명제 대조 후 수정: 실행 전 설계

2026-09-14. 사용자가 보존 방법 보완 시험을 승인했다. 기존 키 재사용 승인을 유지한다. 이 문서는 새 응답 생성 전에 동결하며 실제 시각·해시는 input_freeze_manifest.json을 따른다.

## 질문과 비교

**명제별 대조 결과를 추가하면, 같은 초안을 바로 재작성할 때보다 규범 강도·조건·예외가 최종 설명에 더 잘 보존되는가?** 이전 P1 실험의 모든 추출·설명 6쌍을 seed로 고정한다. 실패 사례만 고르지 않고, 완수·미확정 사례도 포함한다. 기존 원본·평가·원고는 변경하지 않는다.

| 조건 | 같은 seed에 적용할 처리 | 최종 설명 | 새 API 호출 |
|---|---|---:|---:|
| R0_REWRITE | 원문·자동 추출 목록·기존 응답 + 공통 수정 지시 → 바로 재작성 | 6 | 6 |
| R1_AUDIT_REPAIR | 원문·자동 추출 목록·기존 응답 → 명제별 대조 1회 → 대조 JSON을 추가한 동일 수정 요청 | 6 | 12 |

총 18회, 최종 설명 12개다. 과거 초안은 고정된 수정 입력이며 새 동시 생성 대조군으로 가장하지 않는다. 주 비교는 이번에 생성한 R1 대 R0이고, 과거 초안 대비 변화는 보조 분석이다. 3개 원문·각 2개 초안의 사후 개발 진단이며, 처음부터 실행한 전체 파이프라인 성능이나 새 조항 일반화를 측정하지 않는다. 추가 대조 호출·입력량·대조 지시가 함께 늘어나는 묶음 개입이다.

## 대조 출력과 수정 입력

대조는 각 추출 명제 id에 대해 원문 지지 여부(SUPPORTED/CONFLICT/UNRESOLVED), 설명 보존 상태(PRESERVED/OMITTED/DISTORTED/UNRESOLVED), 원문·설명 인용, 필요한 수정을 남긴다. 추출 목록에서 빠진 관련 원문 명제는 additional_source_findings에 기록한다. 내부 사고 과정을 요구하지 않고 관찰 가능한 대조 결과를 얻는다.

추출 목록과 대조 결과는 정답이 아니다. 원문 우선 규칙을 두 조건에 적용하며, 전체 원문을 그대로 유지한다. 기존 평가 요구사항·점수·사례별 정답 힌트는 생성 요청에 넣지 않는다. 사람이 대조를 고치거나 성공 결과만 전달하지 않는다. R1의 최종 입력은 `R0 입력 + 동결 suffix + 줄바꿈 + compact 대조 JSON`이다. 실제 대조 응답 ID·JSON 해시·후속 요청 해시로 연결한다.

R0와 R1의 최종 모델·JSON schema·문장 제한·출력 상한은 같다. 모델 gpt-5.4-mini-2026-03-17, temperature 0, reasoning none, store false, 최종 출력 900토큰, 설명 2~4문장이다. 선행 대조에만 3,000 출력 토큰을 허용한다. 대조 JSON 입력 상한은 UTF-8 24,000바이트다. 원문 추출을 다시 하거나 길이 제한을 완화하지 않는다.

## 실행·비용·검증

12개 수정 슬롯을 고정 문자열과 슬롯 ID의 SHA-256 순으로 실행한다. R1의 대조와 수정은 인접해 순차 실행한다. 반복 번호는 기존 초안 식별자이며 API 난수 seed가 아니다. 입력·출력·요청 규칙·코드·계획을 봉인한다. 모든 기존 P1 seed 포함과 평가 필드 변경이 생성 입력에 영향을 주지 않는지 확인한다.

[공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4-mini)를 2026-09-14 확인했다. 백만 토큰당 입력 $0.75, 캐시 입력 $0.075, 출력 $4.50으로 계산한다. API 비용 한도 $0.50, 전체 보수적 계획 예약액 $0.41614575다. 입력·schema UTF-8 바이트와 2,048 여유량·동적 대조 입력 상한·최대 출력을 반영한 계획 추정이며 사업자 청구 보장은 아니다. 실제 usage를 다시 계산하며 Codex 분석 비용은 별도다.

통신 결과 미상·HTTP 오류·모델 불일치·usage 이상·미완료·schema 오류·크기/예산 초과 시 즉시 중단한다. 자동 재시도·수정 재반복·초안 선택·중단 폴더 재실행은 금지한다. 대조의 명제 ID 누락·중복과 인용 불일치는 별도 진단으로 남기고 의미가 좋아 보이는 대조만 선별하지 않는다. 모든 계획 슬롯의 시도·미시도를 보존한다.

진행 AI가 실행 전 설계를 검토했다. 오프라인 시험으로 동적 요청 연결, 크기 상한, 중첩 schema, 빈 대조의 보존, 잘림, 통신 실패 무재시도, 잘못된 대조 이후 수정 미호출, 재실행 거부를 확인한다. 별도 AI 설계 검토는 아니다.

## 평가·종료 기준

최종 설명 12개를 익명 ID·동일 원문·기존 9개 요구사항으로 진행 AI가 수동 평가하고 먼저 봉인한다. 새로운 대조 내용과 조건 키는 봉인 전 읽지 않는다. 진행 AI는 이전 초안과 평가를 알고 있어 독립 또는 완전 눈가림 평가가 아니다. 요구사항은 1/0/null, 왜곡은 true/false/null을 유지한다. 명확한 요구사항 0 또는 왜곡 true이면 완수 0, 그 외 미확정이 남으면 null, 나머지는 1이다. 문장 수·출처·메타데이터는 별도 진단이며 최종 설명의 누락을 복구하지 않는다. 기존 능력/허용 등의 논점에서 해결되지 않은 표현은 미확정으로 보존한다.

봉인 후 대조 내용과 키를 열어 다음을 확인한다. 자동 대조가 실제 누락·왜곡을 발견했는지, 올바른 내용을 잘못 수정하도록 요구했는지, 지적한 항목이 최종 설명에서 보존됐는지를 원문·인용·수동 판정으로 추적한다. 대조의 PRESERVED 라벨이나 문자열 검사는 정답 판정이 아니다. 기존 초안 판정은 그대로 사용하고 소급 변경하지 않는다.

모든 응답·봉인이 확보되고, R1 확정 완수 > R0 완수 상한, R1 왜곡 상한 ≤ R0 확정 왜곡, R0 확정 완수 쌍의 R1 퇴행 없음, 과거 확정 완수 seed의 R1 퇴행 없음을 모두 만족할 때만 1차 개선 후보로 표시한다. 미충족은 개선 미확정이다. 사람 전문가 또는 두 평가자 검증을 대신하지 않으며, 기존 HOLD를 해제하거나 새 조항 실행으로 자동 확대하지 않는다. 결과가 좋든 나쁘든 이 18회와 1차 진단으로 종료한다. 통계 검정·신뢰구간·모집단 성능을 제시하지 않는다.
