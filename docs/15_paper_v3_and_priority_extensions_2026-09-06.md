## 논문 반영

기존 절·제목·저자·소속·인용 순서를 유지하면서 요약, 연구 질문, 조건 설명, 평가 방법, 표·그림, 결과·한계를 변경했다. 표·그림은 새 첫 평가 C1 61/72, C2 71/72, C3 65/72를 동일한 평가 차수로 제시한다. 이전 점수 65/72·72/72와의 9건 차이를 결과에 공개하고, C3의 개선이 확정되지 않았음을 요약·결론에 반영했다. C0는 이번 3조건 새 의미 평가 대상이 아니므로 최신 표에서 제외했으며 원래 응답·점수는 남아 있다.

독립 전문가 검증과 새 지연 재검토가 미완료인 잠정 원고다. 사용자에게 현재 연구 상태를 보여주는 편집본이며 제출용 최종 결과로 표시하지 않는다. C1M의 아직 평가하지 않은 의미 성능은 이 원고에 넣지 않는다.

KIPS 제공 양식의 페이지 크기·여백·단 속성을 유지했다. 번들 LibreOffice 렌더링 2쪽 전체를 확인했으며 표·그림·한글·캡션에 겹침이나 잘림이 없다. PDF 텍스트에서 저자, 잠정 상태, 핵심 비율과 p-value를 대조했다. C3 인용 ID 71/72는 원본 응답에서 별도 재계산했다. OOXML에서 변경된 기존 package part는 `word/document.xml`과 문서 관계 파일뿐이며 새 그림만 추가했다.

## 확장 1 완료 — 조항 단위 민감도

72개 문장이 44개 조항에 묶인다는 점을 반영해 44개 조항을 복원 추출하고 그 안의 모든 paired 문장을 함께 가져오는 20,000회 cluster bootstrap을 수행했다. 매 표집에서 문장 수가 달라지므로 성공 차이 합계를 해당 표집의 전체 문장 수로 나눈다. seed는 2026090602다. 생성 후 수행한 보조 분석이며 조항 단위의 대표성이나 평가자의 판단 불확실성을 보장하지 않는다.

| 비교 | 차이 | 조항 bootstrap 95% 구간 | 조항 하나씩 제외한 차이 범위 |
|---|---:|---:|---:|
| C3−C1 | +5.56%p | −2.53~+15.52%p | +4.23~+7.81%p |
| C2−C3 | +8.33%p | +1.25~+15.87%p | +6.25~+9.86%p |

C3−C1의 방향은 조항 하나를 제외해도 유지되지만 신뢰구간은 0을 포함한다. 따라서 자동 추출의 성능 향상을 확정하지 않는 원고 결론을 유지한다. C2−C3는 작은 불일치 표본에서 bootstrap과 exact 검정 결론이 다를 수 있어 유의성을 단정하지 않는다.

재현: `python3 tools/c3_clause_sensitivity.py`. 상세 산출물은 `outputs/analysis/c3_clause_sensitivity_pass1.json`이다.

## 확장 2 — 규범 유형 힌트 C1M

원문 C1에 정답 normative_type과 polarity만 추가했다. C2의 높은 점수가 규범 유형 정답을 알려주는 것만으로도 나타나는지 확인하기 위한 oracle 비교다. 자동 추출을 잘한다는 검증과는 구분한다. C2의 나머지 필드뿐 아니라 원래 지시문 차이도 남아 있어 C2−C1M을 순수한 네 필드 인과 효과로 주장하지 않는다.

`docs/14_modal_hint_extension_protocol.md`와 실행 입력을 동결했다. 오프라인 검사에서 72개 모든 행의 다른 gold 필드·case ID를 변조해도 API 요청이 바뀌지 않았고, 추가 블록을 제거하면 기존 C1 프롬프트와 byte 단위로 같음을 확인했다. 모델·출력 상한·schema는 이전 생성과 동일하다. 기존 승인 키를 사용하며 추정 비용 상한은 $0.50이다.
