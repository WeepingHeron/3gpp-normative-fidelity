# C3 확장 의미 평가: 첫 검토 결과

2026-09-06. **C1/C2/C3 설명 216행과 자동 추출 72행의 첫 의미 검토를 완료했다.** 모든 설명에 여섯 항목의 명시적 판정과 개별 근거를 기록했다. 현재 결과는 **잠정 Codex 평가**이며 지연 재검토·불일치 조정 전이다. 사용자는 독립 전문가 확보가 어려워 Codex 검토를 요청했다. 따라서 독립 전문가 검토를 이번 작업의 필수 완료 조건으로 두지 않되, 전문가 검증을 받은 결과로 표현하지 않는다.

## 현재 결론과 잠정 수치

원문에서 자동 추출한 구조를 사용하는 C3는 원문만 사용하는 C1보다 성공 수가 4건 많다. 그러나 이 표본에서 개선이 뚜렷하다고 결론내릴 수는 없다. 추출 결과에는 규범 대상 이동, 부분 부정·수치 한계 소실, 단순 참조의 예외 오분류가 있었다. 정답 구조를 넣는 C2와 실제 자동 추출 C3의 구분을 유지해야 한다.

| 조건 | 설명 완전 보존 | 비율 | Wilson 95% 구간 |
|---|---:|---:|---:|
| C1: 원문 | 61/72 | 84.72% | 74.68~91.25% |
| C2: 원문+정답 구조 | 71/72 | 98.61% | 92.54~99.75% |
| C3: 원문+자동 추출 구조 | 65/72 | 90.28% | 81.26~95.21% |

C3의 보류 1건도 전체 72건 분모의 실패로 포함했다. 성공 수가 많은 조건의 판정을 느슨하게 하거나 미생성을 분모에서 빼지 않았다.

- 주 비교 C3−C1: +5.56%p; case paired bootstrap 95% 구간 −2.78~+13.89%p; 양측 exact McNemar p=0.34375. C1만 성공 3건, C3만 성공 7건.
- 원래 모호성 3건(`MAIN-CAN-004`, `MAIN-SD-002`, `MAIN-CAN-008`) 제외: C1 59/69, C3 64/69, +7.25%p, 구간 −1.45~+15.94%p, p=0.1796875.
- 보조 비교 C2−C3: +8.33%p, 구간 +1.39~+16.67%p, exact p=0.0703125. bootstrap 구간과 exact 검정은 서로 다른 방법이고 작은 불일치 표본에서 결론이 다를 수 있으므로 유의한 차이라고 선언하지 않는다.

20,000회 case bootstrap, seed 2026090601. 새로 발견한 애매한 사례를 성능이 좋아지는 방향으로 제외하지 않았다. 세부 수치는 `summary_pass1.json`에 보관했다. 이 구간은 72문장이 독립 단위라는 근사이며 44개 조항 내 상관과 평가자의 판단 불확실성까지 포괄하지 않는다. C1/C2와 C3의 생성일 차이도 있으므로 탐색적 비교로 한정한다.

## 기존 평가와 달라진 9건

기존 main의 동결 판정은 C1 65/72, C2 72/72였다. 이번에 기존 점수를 가져오지 않고 다시 읽은 결과는 C1 61/72, C2 71/72다. C1은 6건이 성공→실패, 2건이 실패→성공, C2는 1건이 성공→실패로 바뀌었다. 동일 응답 144개 가운데 9개의 완전 보존 판정이 달라졌으므로 기존 높은 평가자 내 일치율만으로 평가 신뢰도를 확정할 수 없다.

실패→성공으로 바뀐 UDSF와 보안 전제 문장은 원문의 make sure/need to를 의무로 번역한 것 자체가 새 의무 추가는 아니라는 판단이다. 반면 can을 허용으로 명시한 경우, 비권고를 강한 금지로 표현한 경우, 일부 대상/용어의 손실은 새 실패로 기록했다. 조건명 복원 전에 판정을 저장하고 해시로 고정했으며, 복원 뒤 기존 결과에 맞춰 점수를 조정하지 않았다.

`archived_vs_fresh_pass1.csv`에 양쪽 판정과 근거를 나란히 남겼다. 기존 main 데이터·응답·점수와 논문 v2는 덮어쓰지 않았다. **논문 v2의 65/72·72/72는 이전 동결 평가의 수치이며, 제출용 최종 수치는 이번 불일치 조정 뒤 확정해야 한다.**

## 자동 추출과 최종 설명을 분리해서 보기

추출 actor/condition/action/exception 슬롯별 일치는 각각 63/72, 41/63, 66/72, 9/26이다. 이 수치를 그대로 정보 손실률로 읽으면 안 된다. condition 또는 exception이 action 안에 옮겨 적힌 경우가 많기 때문이다. 슬롯을 합쳐 구조 정보와 결합 대상을 보존했는지 보면 61/72이며, 이 중 JSON 규범·polarity까지 모두 일치한 것은 57/72다. 이 보조 분석 정의는 생성 후 정했으므로 탐색적이다.

구조 보존 실패 11건 중 최종 설명은 8건에서 완전 보존으로 판정됐다. 반대로 구조 보존 61건 중 설명 실패는 4건이었다. 생성 단계가 원문도 다시 받으므로, 앞의 8건이 자동 추출의 자체 수정 능력을 입증하지는 않는다. 또한 단순 슬롯 오배치, 정답 대상 선택 오류, 추출 입력 자체의 맥락 결손을 구분해야 한다.

`MAIN-SDN-010`의 congestion 조건은 질문과 PDF 앞 문단에는 있지만 추출 단계에 전달한 source 단문에는 없다. 이 조건을 추출하지 못한 것을 모두 모델 오류로 돌리거나 gold로 몰래 채우지 않았다. 다음 버전에서 최소 문맥을 명시적으로 제공할 필요가 있다.

설명과 JSON의 규범 유형 일치도 별도 대조했다. C3는 일치 66건, 불일치 3건, 규범 범위 혼합 또는 미생성으로 판정 곤란 3건이다. 이는 gold 정확도와 다른 지표이며, 틀린 유형을 두 곳에서 동일하게 쓰는 것도 일치에 포함된다. 명시적 규범 강도 판정에서 파생한 보조 결과다.

## 다음 검토와 실험 보완

1. **9월 7일 14:08:18 KST 이후** 새 순서·새 ID로 최소 24시간 간격의 pass 2를 수행한다. 216행 전수 재검토를 유지하고 이전 점수는 채점 후에만 대조한다. 시간 경과만으로 독립성이나 기억 제거가 보장되지는 않는다.
2. 판정이 달라진 9건, 규범 범위가 애매한 사례, 비트 조건의 압축 설명, 일부 강한 한국어 표현을 우선 조정한다. pass 2 전 자료에는 이전 판정과 조건 대응 키를 섞지 않는다.
3. 조정 후 논문 수치와 연구 결론을 갱신한다. 현재 결과로 자동 추출의 우월성을 주장하지 않는다.
4. 그다음 별도 C3 v2에서 규범의 대상 절, 양화(not all/98%), 부정 범위, reference/exception 분리를 보완한다. 필요한 최소 원문 문맥을 추가하되 정답 구조를 입력하지 않는다. 이번 실패 사례로 개선했다면 같은 72개는 개발 표본으로 보고 새 문장·조항에서 검증한다.

이번 의미 평가는 추가 API 호출 없이 진행했다. 미리 정한 24시간 간격 때문에 오늘 수행한 점검을 pass 2 완료로 표시하지 않는다. 자동 재실행이나 예약 알림은 설정하지 않았다.
