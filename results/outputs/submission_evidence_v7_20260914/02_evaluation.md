# 평가표와 해석 범위

사용자 요청에 따라 사람의 독립 검토는 생략했다. 모든 의미 판정은 동일 Codex 기반이며 점검 통과를 독립 전문가 검증으로 표현하지 않는다. 원고 v7에도 한계를 유지한다.

| 구분 | 대상 | 판정 방식 | 남은 제한 |
|---|---|---|---|
| 주 분석 | 49개 원문 × 5조건 | 동결 v2 기준, 두 차수와 불일치 조정 | 동일 AI·사후 처리·U 잔존 |
| 민감도 | 50/50/51개 원문 × 5조건 | 동일 조정 판정에 고정 집합 적용 | 중첩 집합, 새로운 반복 아님 |
| 추가 진단 | 알려진 3원문, 완료 8응답 | 사전 지정 9요구사항, 당일 동일 AI 재검토 | 원문 전체 완역 지표 아님; 통신 미상 1 별도 |

| 상태 | 의미 | 분모 처리 |
|---|---|---|
| P | 필수 의미 보존 및 미지원 규범 추가 없음 | 성공 1 |
| F | 명확한 누락·왜곡 | 성공 0 |
| U | 판정 미확정 | 제거하지 않음; 원자료 null |
| NG | 미생성 | 의미 오역과 구분, 고정 분모에서 성공 0 |

논리적 범위는 [P/N,(P+U)/N], B−A 차이는 [(P_B−P_A−U_A)/N,(P_B+U_B−P_A)/N]이다. 신뢰구간이나 통계적 유의성이 아니다. 추가 첫 통신 미상 슬롯은 결과 자체를 확인하지 못했으므로 확인된 NG와 혼동하지 않으며, 9개 전체 완수율을 보고하지 않는다.

## 추가 진단의 동결 요구사항

| 사례 | ID | 요구사항 |
|---|---|---|
| CTX-001 | CAPABILITY_POSSESSION | 각 SMF의 능력 보유 여부가 선택적임을 보존한다. 이미 모든 SMF가 능력을 보유한다거나 제어 행동의 허용으로 바꾸지 않는다. |
| CTX-001 | BOTH_WITHIN_ONE_SESSION | 능력의 대상은 하나의 PDU Session에서 local UPF와 central UPF 모두를 제어하는 것이다. |
| CTX-002 | STORAGE_RECOMMENDATION | 비-SNPN 모드에서 allowed NSSAI를 ME 비휘발성 메모리에 저장하는 권고 및 Annex C 연결을 보존한다. should를 무조건 의무로 바꾸지 않는다. |
| CTX-002 | IDENTITY_BINDING | SUPI와 함께 저장하고 일치할 때만 allowed NSSAI를 사용하며 불일치하면 삭제한다는 조건을 보존한다. |
| CTX-002 | EMERGENCY_EXCEPTION | 긴급 서비스 등록 시 USIM/비휘발성 저장은 금지되고 ME에 임시 저장하며 긴급 서비스 등록 해제 시 삭제한다. |
| CTX-002 | ECALL_EXCEPTION | eCall only 시 USIM/비휘발성 저장은 금지되고 ME에 임시 저장하며 eCALL-INACTIVE 진입, 전원 꺼짐 또는 USIM 제거 시 삭제한다. |
| CTX-003 | LOCATION_UNLESS_RECOMMENDATION | PLMN 운용 불가 지역에 UE가 있음을 판단할 충분히 정확한 위치정보가 없는 한 AMF의 요청 거절 또는 UE 등록 해제를 하지 않는 권고를 보존한다. |
| CTX-003 | SATELLITE_SCOPE | NR 위성 접속의 위치 검증 문맥으로 범위를 한정한다. 모든 NR 접속에 무조건 확장하지 않는다. |
| CTX-003 | CONFIGURED_VERIFICATION | 망이 PLMN 운용 가능 여부를 검증하도록 설정된 위치 검증 문맥임을 설명한다. 위치 검증 자체를 항상 의무로 바꾸지 않는다. |

복합 요구사항은 모든 접속항·예외 사건을 확인한다. explanation_ko만 의미 채점하며 action/exception 등 메타데이터로 누락을 복원하지 않는다. 명확한 누락 0과 해석 불확실 null을 구분한다.

## 경계 사례

- 성공: SMF가 능력을 가질 수도 있다고 하여 보유의 선택성을 보존한 설명. capability 메타데이터만으로 설명을 실패로 바꾸지 않는다.
- 성공: 저장해야 한다는 권고는 전체 표현의 권고 한정을 반영한다. 해야 한다만 검색해 의무화로 세지 않는다.
- 실패: eCall 임시 저장이 메타데이터에만 있고 설명에는 없는 경우. 긴급 등록의 규칙을 eCall에 자동 확장하지 않는다.
- 실패: NAS 메시지 대신 수신 엔티티가 검사를 받은 것으로 서술한 V2-P2-099.
- 미확정: V2-P2-106의 능력이 있다와 이는 선택 가능의 지시 대상이 불명확한 설명.
