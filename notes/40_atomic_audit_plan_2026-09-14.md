# 의미 요소별 대조의 재검증: 실행 전 설계

2026-09-14. 사용자가 제안한 검증을 승인했다. 기존 키 재사용을 유지한다. 이번에는 최종 설명을 고치지 않고 **대조 자체의 오류 탐지와 근거 연결**을 비교한다. 이전 실험·판정·원고는 보존한다.

기존 P1의 추출·설명 6쌍 전체를 고정 입력으로 쓴다. 각 입력에 기존 명제 단위 대조(C0)와 의미 요소별 대조(C1)를 한 번씩 새로 적용하여 대조 12개를 생성한다. 기존 대조를 새 대조군으로 재사용하지 않는다. 이전에 관찰한 원문 3개·초안 6개에 대한 사후 개발 시험이며 새로운 조항 성능이 아니다.

C1은 MODALITY, ACTOR_ACTION, SCOPE_CONDITION, EXCEPTION, FOLLOWUP 차원별로 해당 의미 요소를 나누고, 독립적인 조건·사건은 별도 행으로 기록한다. 각 행은 명제 ID·차원·원문 지지·설명 상태·연속된 원문 및 설명 인용·필요 수정을 가진다. 한 부분이 보존됐다는 이유로 복합 명제 전체를 통과시키지 않는다. 추가 원문 발견은 같은 목록에 넣고 상충하는 중복 판정을 피하도록 지시한다. 없는 차원을 억지로 만들지 않는다. 추출 목록은 정답이 아니며 원문을 우선한다.

C0와 C1의 원문·추출·초안, 모델 snapshot gpt-5.4-mini-2026-03-17, temperature 0, reasoning none, store false는 동일하다. 대조의 출력 상한은 **두 조건 모두 6,000토큰**이다. C0 지시는 이전과 같지만 이전 실험의 3,000 상한과는 다르므로 역사적 결과와 같은 조건이라고 주장하지 않는다. C1은 항목 세분화·근거 인용·일관성 지시와 schema를 함께 바꾸는 묶음 개입이다. 설명의 2~4문장 제한은 입력 초안의 속성이며 이번에는 새 설명을 생성하지 않는다.

생성 요청은 이전 생성 전 동결 요청에서 파생한다. 평가 요구사항·점수·사례별 정답은 넣지 않는다. 12개 요청을 고정 문자열+슬롯 ID 해시 순으로 순차 실행한다. 전체 정적 요청·schema·계획·코드를 실행 전에 동결한다. 재시도·부분 선택·대조 수정·실행 중 파라미터 변경은 없다. 통신/HTTP/모델/usage/완료/schema 오류 시 중단하고 모든 슬롯을 기록한다.

[공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4-mini)를 2026-09-14 확인했다. 백만 토큰당 입력 $0.75, 캐시 입력 $0.075, 출력 $4.50이다. 입력·schema UTF-8 바이트+2,048 여유량과 최대 출력으로 계산한 전체 예약 추정은 $0.428268, 생성 API 한도는 $0.50이다. 사업자 청구 보장은 아니며 반환 usage로 재계산한다. Codex 분석 비용은 별도다.

## 평가와 종료

기존 P1의 봉인된 18개 요구사항 판정 및 원문·초안을 기준으로 진행 AI가 대조 12개를 수동 검토한다. 이전 AI 판정은 개발 참조이며 사람 전문가 gold가 아니다. 원판정을 변경하지 않는다. 주 지표는 **기존 요구사항 0 중 실제 결함을 명시적·정확하게 지적한 수**다. 복합 항목의 일부 결함만 찾은 경우, 상충하는 지적, 근거 없는 선언을 구분하여 기록한다. 정확한 탐지는 source/draft에 근거하며 잘못된 수정을 요구하면 별도 오류로 센다.

고정 분모는 조건당 요구사항 18개다. 기존 요구사항 1에 대한 오탐, 미확정 추가 주장에 대한 강제 통과, 잘못된 수정 지시, 인용 불일치·중복·명제 ID 미검토를 별도로 보고한다. 항목 수가 늘어난 C1의 행 개수 자체를 정확도나 독립 표본 수로 비교하지 않는다. 동일 과제 요구사항에 대응시켜 비교한다. 어떤 요구사항을 일관되게 판정하기 어렵다면 미확정으로 남긴다. 문자열 일치는 근거 존재만 검사하고 의미 점수를 만들지 않는다. 실제 인용이 해당 의미를 지지하는지는 수동 확인한다.

최종 대조는 schema로 조건을 추측할 수 있고 진행 AI가 설계·이전 오류를 알고 있으므로 눈가림·독립 검토라고 주장하지 않는다. 새 대조 12개와 수동 판정을 봉인하고 모든 결과를 보고한다. C1이 알려진 결함을 더 많이 찾고, 보존된 요구사항의 오탐과 잘못된 수정 지시 사례가 추가로 늘지 않으며, 전달·봉인이 정상일 때만 1차 대조 개선 후보로 기록한다. 근거·중복 진단은 별도 공개하며 완벽한 의미 검증을 뜻하지 않는다. 실패하면 개선 미확정이다.

이번 12개 대조와 1차 평가로 종료한다. 설명 재생성·수정·새 조항 실행으로 자동 연결하지 않는다. 이전 HOLD는 유지한다. 3개 선정 개발 원문으로 p값·신뢰구간·일반 성능을 보고하지 않는다.

진행 AI가 정적 요청 파생, 동일 토큰 상한, 모든 6개 seed 포함, 생성/평가 분리와 비용을 검토했다. 오프라인 시험은 중첩 schema, 빈 대조가 의미 승인이 아님, 전달 실패 시 중단, 통신 무재시도, 미상 비용, 재실행 거부를 확인한다. 실행기 재사용에 따른 usable_explanations·parsed.explanation 관련 일부 회계 필드명은 **이번 실험에서는 유효한 대조 응답 수**를 뜻하며 최종 설명 생성 수가 아니다.
