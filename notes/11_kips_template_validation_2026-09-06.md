검증일: 2026-09-06. 제공된 폴더의 `KIPS 학술발표대회 논문양식_v1_word.doc`를 번들 LibreOffice로 DOCX 변환해 대조했다. 동봉 HWP는 별도로 편집하거나 동일성을 인증하지 않았다. 원본 양식의 예제 연구·저자·소속은 본 논문에 복사하지 않았다. 문서 내 제출 안내는 양식 요구사항으로 사용했으며 실제 제출·로그인·등록 지시로 실행하지 않았다.

## 내용 보완

- C2는 평가 gold 구조를 입력받는 oracle structured 조건임을 명시했다.
- 라벨 자체 검토와 지연 의미 평가가 Codex 기반이며 독립 전문가 검증이 없음을 명시했다.
- JSON modal 정답률·한국어 설명 완전 보존·출처 ID 복사를 구분했다.
- 모호한 3건은 실행 전 지정이 아니라 1차 평가 후 지연 2차 평가 전에 기록한 것으로 정정했다.
- 69건 민감도 분석의 exact McNemar p=0.125와 C2 72/72의 Wilson CI 94.93~100%를 추가했다.
- 기존 이미지의 잘린 축 글자 조각을 없애고 같은 6×3 성공 수를 인쇄용 크기로 다시 그렸다.
- 원래 main 데이터·prompt·rubric·응답·채점을 변경하지 않았다. 새 확장 결과는 아직 이 원고의 확정 결과로 반영하지 않는다.

## 산출물과 검증

현재 편집본은 `outputs/paper/ACK2026_3GPP_normative_fidelity_draft_v2.docx`, 배포용 PDF는 같은 이름의 `.pdf`, 내용 대조용 Markdown은 `.md`이다. v1은 보존했다. v2 Markdown은 수정 DOCX 내용에서 생성해 수치·방법 서술을 맞췄다.

- DOCX SHA-256: `3e87700e46cf88c004df60a26dfa0bc5afc861d3bbe03415638dcf8619887714`
- PDF SHA-256: `d0bb0c21d0b52068cdb960999fe45b66f06d2545832d192bb946e15dcd056914`
- renderer 출력 두 페이지를 전부 시각적으로 확인: 한글 표시 정상, 표·그림·캡션의 잘림/겹침 없음.
- PDF 파서 확인: 2쪽, 저자·소속·핵심 수치·Codex 텍스트 추출 가능, replacement character 없음.
- PDF의 명조·고딕 글꼴 embedding 확인. DOCX 추적 변경·댓글 참조 각 0개, 첫 인용 순서 [1]~[9] 확인.
- 제공 양식과 v2의 pgSz·pgMar·cols XML 속성 대조 통과.
- 기존 동결 18개 파일 및 output freeze 7개 파일 검증 통과.

이전 검토에서 한글이 보이지 않았던 원인은 현재 변환 환경의 fontconfig 경로였다. Mac 시스템·사용자 글꼴 경로를 지정한 뒤 원본 v1과 수정 v2 모두 한글이 정상 출력됐다. 원본 파일 손상으로 판정하지 않는다.

독립 전문가 gold·응답 검토는 아직 수행하지 않았다. 양식·렌더링 확인은 연구의 의미적 정확성이나 학회 접수·채택을 뜻하지 않는다.
