# 두 AI 의미 평가 계약

이 문서는 실행 전에 고정하는 평가 지침이다. 아직 모델 응답이나 판정이 없다.

평가자는 reviewer/packets_18.jsonl의 18개 패킷을 각각 검토한다. 제공된 원문·질문·문맥·요구사항과 해당 응답만 판정 근거로 삼는다. 조건 키, 생성 프롬프트, 과거 판정, 다른 평가자의 판정, 조건별 집계는 열지 않는다. 설계를 아는 진행 AI의 사전 지식은 없앨 수 없으며, 별도 AI는 그 기록을 전달받지 않은 새 문맥에서 평가한다. 평가자는 실제 읽은 파일과 자신이 알고 있던 배경 범위를 manifest에 기록한다.

각 평가에서 review_id, reviewer, 실제 reviewed_at, 요구사항별 value·response_quotes·source_quotes·rationale, full_context_target_completeness, unsupported_or_distorted_claim와 인용·사유, metadata_inconsistency와 사유, citation_diagnostic, sentence_count_diagnostic, overall_rationale를 작성한다. 모든 인용은 제공된 응답이나 원문에 존재해야 한다. 누락은 없는 문장을 인용하는 대신 빠진 명제를 구체적으로 기술한다. 판정은 수동으로 하며 키워드 포함 여부만으로 의미 점수를 생성하지 않는다.

정상 설명의 요구사항은 1/0/null, 미지원·왜곡과 메타 모순은 true/false/null을 사용한다. null은 의미가 해결되지 않은 경우이며 근거와 해석 후보를 남긴다. 모든 조건·예외·후속 행동이 보존돼야 복합 항목을 1로 본다. 하나라도 명확한 요구사항 0 또는 확인된 미지원·왜곡 true이면 전체 완수 0, 그런 실패 없이 null이 남으면 null, 나머지는 1이다. 메타데이터와 문장 수·인용 진단은 설명의 의미 점수를 복구하거나 단독으로 깎지 않는다.

semantic_status가 NOT_ASSESSABLE인 전달 실패 응답은 요구사항과 왜곡/메타 판정을 문자열 NOT_ASSESSABLE로 기록한다. 파이프라인 전체 완수는 0이고 사유는 전달 상태다. 이를 의미가 불명확한 null이나 왜곡이 없는 false로 바꾸지 않는다. 중단 실행의 NOT_OBSERVED 슬롯은 이 정상 완료 패킷 생성기의 평가 대상이 아니며 별도 실행 회계표에 남긴다. 전달 실패나 미관찰을 숨기고 분모를 줄이지 않는다.

완료한 판정과 검토 기록을 실제 완료 시각, 입력·출력 SHA-256과 함께 봉인한다. 두 평가자 모두 봉인하기 전에 비교하지 않는다. 판정 차이는 원본 그대로 남기고 조건별 결과를 각 평가자별로 계산한다. 나중에 조정하더라도 별도 사유·시각·버전의 기록으로 남긴다. 두 AI의 평가를 독립적인 생성 표본이나 사람 전문가 검증으로 해석하지 않는다.
